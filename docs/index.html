Latium

An open-source research framework for reimplementing knowledge-editing methods across state-of-the-art language models. Latium currently supports ROME and adds tooling for causal tracing, edit detection, and artifact-based analysis.

A joint project by Security@FIT and Red Hat as part of the LLM Forensics research initiative.

What it does

Latium provides a common workflow for implementing, running, and evaluating knowledge-editing methods across model architectures. ROME is currently supported. The framework also includes automatic causal tracing, structural edit detection, artifact capture, model-free analysis, and reproducible graph rendering.

Automatic causal tracing

Latium corrupts the full subject-token embedding span and restores overlapping windows of full MLP outputs. It discovers candidate regions on one fact split and requires positive recovery on a held-out split before reporting a representative layer.

Causal trace→Held-out confirmation→Second moment→ROME benchmark

The detector-free cluster pipeline passes the confirmed layer at runtime, leaves model configuration files unchanged, and produces a validated pipeline summary.

Quick start

Setup

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
make mkdir

Inspect available methods

python3 -m src methods

Prepare second-moment statistics

ROME normally requires covariance statistics for the selected model.

python3 -m src second-moment model=gpt2-large

Run and inspect one ROME edit

python3 -m src manual-rome model=gpt2-large

Run automatic causal tracing

python3 -m src causal-trace \
  model=gpt2-large \
  command.causal_trace.num_valid_facts=100

Run structural capture, analysis, and graphs

python3 -m src structural run \
  'structural.run.models=[gpt2-large]' \
  structural.run.n_tests=30 \
  structural.capture.profile=paper \
  structural.analysis.preset=paper \
  structural.render.enabled=true

Run the causal-to-ROME cluster pipeline

jobs/submit.sh causal-rome -- \
  pipeline.model=gpt2-large \
  pipeline.causal_trace.num_valid_facts=100 \
  pipeline.rome.n_tests=30

Commands use Hydra overrides and run through python3 -m src. See the repository README for all configuration options and remote execution details.
